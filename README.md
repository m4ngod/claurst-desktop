# Claurst Desktop

基于 Claurst 0.2.0 的独立 Apple 芯片 Mac 应用。原生 SwiftUI 界面采用对话为主的 A 布局，按需展开成果侧栏。执行通过 Claurst ACP，不依赖官方 Claude Code。

当前支持新任务、流式回复、任务隔离、模型设置与系统钥匙串存储，以及文本文件读取、来源行号、文件创建与覆盖、真实差异和越界授权。已加入停止、补充要求、关键问题回答，以及退出后查看历史并继续。已接入文字型 PDF、DOCX 正文解析、XLSX/CSV 读取和分组求和、本地扫描识别、经能力检查的模型图像读取、联网搜索与网页来源，以及离线 LaTeX 编译和 PDF 预览。混合素材串联回归及真实研究窗口验收已通过。首个未公证预览版已公开，并通过干净 macOS 27.0.1 虚拟机的 Safari 实际下载、用户允许后启动与真实 Qwen 读写复验。阿里云服务上的 Qwen 和 Deepseek 均已完成可复现的搜索状态修复样例；Qwen 经人工纠正与续行交付十页研究报告并完成页面核对。2026-10-22 用户取消第二家独立服务的首版验收要求。实际验证范围与已观察到的限制见 [模型兼容记录](docs/build/model-compatibility.md)。

## 构建和运行

开发环境需要 Apple 芯片 Mac、Swift 5.8 或更新版本（Xcode 或 Command Line Tools）、Python 3 和可下载依赖的网络。当前实际构建宿主为 macOS 27.0.1（此前验证使用 14.2.1）；已在没有 Xcode、Rust 或 TeX 的 macOS 27.0.1 虚拟机验收当前候选，其他系统版本尚未完成安装验收。

单独运行[第三方证据收集工具](docs/build/third-party-audit.md)需要 Python 3.11 或更新版本，用于读取 Cargo.lock；该要求不影响应用运行。

在仓库根目录执行：

```sh
./scripts/bootstrap.sh
./scripts/setup-dev-signing.sh  # 首次设置；后续复用固定证书
./scripts/build-desktop.sh
./scripts/open-desktop.sh
```

工具链、CMake 与缓存放在本项目 `.build-tools`，不修改系统 PATH。Rust 源码由 Cargo.lock 锁定；本地验证使用 Rust 1.99.1、Swift 5.8.1、CMake 3.31.6。每次构建生成独立的 `.build/desktop-builds/build-*/Claurst Desktop.app`，最新路径保存在 `.build/latest-desktop-app.txt`，启动脚本打开该构建的新实例。不要覆盖正在运行的应用包，否则可能破坏其钥匙串访问身份。生成的 `.app` 固定使用 `.build-tools/signing/identity.txt` 中的证书指纹、`local.claurst.desktop.dev` 应用标识和绑定该证书的身份要求；证书缺失即停止，不回退临时签名。首次设置在没有既有开发证书时创建本机自签证书，私钥留在钥匙串。自签证书仍受钥匙串的逐构建代码哈希分区限制，不能保证更新后免授权；有 Apple 颁发的证书时，用 `./scripts/setup-dev-signing.sh --identity <证书指纹>` 显式固定该身份。尚未取得正式分发签名或公证，不代表已经通过安装或分发验收。

选择文件夹，在「模型设置」填写非 Claude 服务的 OpenAI 兼容 API 地址（含 `/v1` 等路径）、模型与密钥。密钥保存在 macOS 钥匙串；普通配置只保存引用。点「保存并检查连接」会发出真实文本请求，并用临时样本检验工具读取和结果回传。连接检查还会发送合成随机色块检验图像输入；这不保证任意材料的识别准确率。每个任务绑定第一次发送时的模型配置；修改连接设置后请新建任务，或恢复原配置继续。

目前可要求读取工作文件夹中的 Markdown、文本、文字型 PDF 与 Word（.docx）。目录内读取自动执行；目录外读取先显示授权，允许仅对这一次有效。来源面板显示实际打开文件的路径、行号、PDF 页码或 DOCX 段落号及读取时内容，可打开原文件或在 Finder 定位。选择文件夹不会上传整个目录；实际读取的内容会作为工具结果发给所选模型。

PDF 仅提取文字层；DOCX 按正文 XML 顺序计段，含表格和空段落，不提供固定页码。DOCX 不读取页眉页脚、批注、脚注、文本框或图片，忽略删除修订、保留插入修订；嵌入正文和兼容性替代内容明确拒绝。旧 .doc、.docm、加密、损坏及无可提取文字的文件会说明原因，不生成已读来源；Read 本身不进行 OCR，扫描件使用下面的识别功能。每个 PDF/DOCX 上限 32 MiB，DOCX 正文展开上限 16 MiB；每次默认 10 页/段，最多 20 页/段及 50 KiB 文字，部分读取与空白选区均给出范围和续读位置。解析在禁止网络和用户文件访问的独立进程中进行，只接收已授权文件句柄读取的字节。来源记录用于核对模型的总结和引用，不能保证模型不会引用错位。

表格工具支持未加密 XLSX 和 UTF-8 逗号 CSV，保留工作表、单元格及 CSV 记录/物理起始行；来源预览包含实际读取与计算记录。分组求和使用十进制计算，列出方法、输入范围、有效值和缺失值数量；缺失金额跳过计数，不填零。非数值、分组缺失或统计列中的公式/错误会拒绝计算。普通 Excel 公式仅展示原有缓存并标记未重新计算，复杂公式或无法保留数值精度的工作簿明确拒绝；不支持旧 Excel、宏或加密格式。每个文件最多 16 MiB、50,000 行、256 列和 500,000 单元格，每次读取最多 200 行、输出最多 50 KiB；超限说明原因，不伪造或静默截断结果。统计不修改原文件，组件缺失时提示重新构建或安装应用。

扫描 PDF 和 PNG/JPEG 可使用本地系统 OCR，保留页码、识别区域和分数；分数不代表准确率，手写、公式和复杂表格须核对原稿。需要模型查看图片或 PDF 页面时，只有通过图像能力检查的当前配置才允许发送经方向校正、去除原始元数据的副本；能力缺失或页面无法可靠绘制会明确报错。原件不修改。具体边界见 [扫描与图像验收](docs/build/verification-12-image.md)。

当前 macOS 27.0.1 虚拟机的本地 Vision OCR 失败，宿主同样例可用。干净环境扫描读取使用已经验证的 Qwen 图像能力；这不表示本地 OCR 在该虚拟机已修复。最终研究结论曾经人工纠正未证实的资料关联，模型输出仍须依据来源核对，见 [干净环境记录](docs/build/clean-mac-acceptance.md)。

「模型设置」可显式开启当前服务的 Responses API 联网搜索；仅适用于该服务支持 web_search 的情况，搜索词会发给所选服务及其搜索提供方。检索失败不切换到其他服务；搜索候选只有实际读取网页后才成为带标题、URL、访问时间和行号的来源。关闭搜索仍可读取指定公开网页。见 [联网验收](docs/build/verification-13-search.md)。

LaTeX 使用应用内置 Tectonic 和固定基础中文资源离线编译，不要求安装系统 TeX。主文件、章节、图片、参考文献须放在工作文件夹；PDF 成果可切换当前主文件与编译日志、查看警告和导出。未包含的宏包或字体会说明原因，不在任务期间下载；编译成功不代表内容与页面布局已核对。完整范围与构建依赖见 [编译组件说明](docs/build/latex.md)；混合素材的确定性验证见 [研究串联记录](docs/build/verification-15-research.md)。

也可要求在已有目录中创建或修改 UTF-8 文本文件，移动、重命名或删除普通文件。目录内操作自动执行；覆盖前须先读取，读取后发生的外部编辑会触发冲突提示。修改前版本先保存到任务运行目录，保存失败时不修改原文件。「素材与成果」中的文件修改可查看当次变化、打开当前文件或在 Finder 定位，并从记录恢复。恢复在本地执行，无需模型连接或密钥；越界恢复仍须授权。重开后记录和恢复结果会保留。

文件整理支持不超过 32 MiB 的文本和二进制文件；写入仅支持 UTF-8。移动要求目标目录已存在、位于同一卷且目标名称未被占用。恢复会检查写入或移动后的内容，原路径被占用或内容已改变时拒绝操作，并显示原因与保留的恢复材料位置。恢复删除保存文件字节和普通访问权限，不保留扩展属性、ACL、硬链接关系或原时间戳。文件夹、符号链接、更大的文件和外部命令造成的修改不在恢复范围内。跨任务操作使用文件锁，提交前再次检查内容与文件身份；这不构成对所有外部编辑器的绝对互斥。

恢复还会验证原目录的设备和文件标识，拒绝被替换或经符号链接重定向的目录。早期开发版的记录若缺少目录身份，只能查看保留材料，不能自动恢复。

已接入项目检查命令：Bash 固定通过 macOS Seatbelt 执行，允许读写所选工作区和该次命令的独立临时目录，只读必要系统运行库；网络与其他用户文件默认不可访问。可针对已存在的额外路径请求单次只读授权，界面列出命令与实际规范路径；拒绝或停止后不执行，不提供脱离隔离的回退。系统隔离不可用时直接报错。工作区中存在硬链接、无法检查的目录或超过 30 万条目时拒绝命令并说明原因，以免修改范围外的文件别名。

执行记录显示实际标准输出、错误输出和退出码；每个输出流最多保留 64 KiB，超过时标注截断。默认超时 120 秒，上限 10 分钟。停止和超时会结束命令进程组，已发生的修改不会撤销；主动脱离进程组的程序可能继续运行，但仍继承文件和网络隔离。命令不加载用户 shell 配置、环境凭据或应用钥匙串；第三方工具链可通过额外只读路径授权，缺少依赖、网络受限和检查失败均不算通过。当前隔离已在 macOS 27.0.1 验证，不代表其他系统版本均已验收。

项目检查会单独记录实际命令结果：退出码 0、失败、主动跳过和未运行。跳过会保留助手给出的原因，并保证该命令不执行；缺少回执的中断标为结果未确认。退出码只反映整条命令；包装命令可能掩盖内部失败，须核对输出，不保证所有问题已解决，后续修改须重新检查。文件修改同时显示助手提供的修改原因，未提供时明确标注。可复现的搜索状态样例位于 `tests/fixtures/search-project`，请复制到临时目录进行修复验收。

运行时可点击「停止」，界面会先显示「正在停止」并等待已启动操作结束；停止不会撤销已完成的文件修改。运行中发送补充要求会先停止当前轮，再按收到顺序继续；点击停止可取消自动继续，未应用的要求会保留。助手的关键问题可选择选项或输入回答。模型请求失败、运行时断开或应用退出后，可依据保存的可见历史继续；恢复不会自动重放旧工具操作，修改前须重新读取当前文件，越界操作重新授权。

配置不从已有 Claurst CLI 设置、环境密钥、项目授权或钩子自动导入。应用配置位于 `~/Library/Application Support/ClaurstDesktop`，每个任务的运行数据独立存放于其 `runtime/<任务标识>`，不因此取得其它任务目录的读取授权。`history` 保存可见对话、执行记录、来源和修改记录，排除模型密钥与隐藏推理。旧版只在内存中的未保存对话无法追溯恢复。

正常退出和异常结束后可从最近任务打开历史；未完成执行显示中断，缺失文件和损坏记录会提示处理方式。历史文件按任务隔离，损坏文件不会被静默覆盖。同一任务由一个应用实例使用，其他实例可查看，关闭原实例后重新载入可继续；任务切换分别保留输入草稿。恢复不保证从任意进程指令精确续跑。

./scripts/test-desktop.sh

cargo test --manifest-path vendor/claurst/src-rust/Cargo.toml -p claurst-acp --locked

## 本地候选包

开发构建显式指定 Apple 芯片 macOS 13 目标，并核对五个实际二进制的架构、最低系统、系统动态依赖和固定签名身份。macOS 13 是编译目标，当前实际验证宿主仍为 macOS 27.0.1，尚不能承诺其它系统版本已通过安装验收。构建期间源码发生变化会停止发布最新应用路径。

提交构建输入并重新构建后，可运行 `sh scripts/package-desktop.sh` 生成 `.build/packages/candidate-*`。其中包含本地签名应用 ZIP、与构建输入逐文件匹配的提交源码 ZIP、构建记录、包检查报告、解压功能回归日志和 SHA-256 校验值。打包必须通过当前 DesktopCore 驱动包内组件的混合研究检查；这不替代打包 UI 或无开发环境验证。`candidate-mpGA4v` 已有独立的干净 Mac 功能验收证据，后续包须按实际变化复验。GPLv3 许可选择已确认；最新 `candidate-lxG7UT` 已完成说明窗口、原文导出和包内回归，见[复验记录](docs/build/verification-19-notices.md)。GitHub 已公开上述未公证预览版及源码材料；Developer ID 分发与公证尚不具备账户条件。实际浏览器下载后的启动验收见[公开下载记录](docs/build/public-download-verification.md)。
