# 需求讨论记录

更新日期：2026-10-21。状态：需求讨论中，尚未形成最终规格。

## 已确认

- 基于用户提供的 Claurst 0.2.0 源码构建独立桌面应用，不依赖真正的官方 Claude Code 程序。
- 界面参考 Claude Code 桌面版风格。
- 项目同步开源到 GitHub，供用户本人和其他人下载使用。
- 产品是通用桌面助手：既处理编程、修改项目等任务，也处理和整理文档、利用本地素材与数据研究写作，并检索互联网信息。
- 用户举例：利用已有素材与数据完成一份论文。具体处理流程及验收要求待讨论。
- 首版资料读取范围包含文字型 PDF、Word、Excel/CSV、Markdown、纯文本，以及扫描版 PDF 和图片识别。扫描件中公式、表格、手写内容等的识别要求仍待细化。
- 论文、报告类写作成果以 LaTeX 源文件和编译后的 PDF 交付；Word 导出不是当前确认的首版要求。
- 通过设置页面配置模型服务地址、模型名称和 API Key。用户没有指定模型厂商，明确“除了 Claude 都可以”；产品应不绑定单一厂商，不采用 Claude 作为执行、识别或回退模型。具体接口类型与首批验证的服务待确定。
- 首个公开版本支持 Apple 芯片 Mac；Intel Mac 与 Windows 不属于首发范围。
- 编程任务与文档研究同等优先，首版需分别验收完整流程。
- 用户选定文件夹后，助手默认可自动处理其内容，包括改动原文件；覆盖、移动和删除原文件不默认逐次弹窗确认。文件夹之外的访问范围及恢复机制尚未确定。
- 需求规格和开发任务目前保存在本地 Markdown 文件中，保留五种默认任务状态。未来代码托管到 GitHub 不自动改变任务保存位置。
- 用户授权常规实现选择：优先复用 Claurst 已有做法；缺失能力参考 Codex 已公开且可核实的行为设计。此授权针对工作方式与技术选择，界面仍参考 Claude Code 桌面版；不要求用户逐项决定底层技术细节。

## 按用户授权采用的默认设计

以下是本项目的设计选择，不代表 Codex 内部实现事实；具体库、服务和接口在开发前验证。

- 文档处理：将格式解析、文字识别、页面查看与文档生成封装成工具，配合按任务加载的技能。优先在本地解析和识别；需要视觉理解时按用户配置的非 Claude 模型能力处理相关页面，并在设置中明确任务文字和图片会发送到所选模型服务。模型不具备视觉能力时明确说明能力缺口，不声称已经读取图像内容。
- 联网研究：复用 Claurst 的搜索和抓取实现作为基础，向用户提供统一的搜索与网页阅读操作及可追溯来源。保留搜索服务配置；默认搜索方案须通过完整网页检索验证，不把 DuckDuckGo Instant Answer 当作完整搜索，也不承诺任意模型 API 都附带搜索。
- 写作流程：根据任务连续推进阅读素材、补充检索、写作、生成 LaTeX、编译和检查 PDF；用户可以随时停止或补充要求。仅在关键资料缺失、目标存在实质歧义或需要超出授权范围时提问，不强制每篇文档都先确认大纲。
- 事实与引用：引用关联实际读取的本地资料位置或网页来源；明确无法验证的引用和缺失数据，不将缺失数据补成事实。

参考依据：

- [OpenAI 官方技能文档](https://learn.chatgpt.com/docs/build-skills)：技能由说明和可选脚本、参考资料构成，可按任务需要加载。
- [Codex CLI 官方文档](https://learn.chatgpt.com/docs/codex/cli)：公开提供图片输入、会话恢复和联网搜索等交互能力。
- [OpenAI 文件输入文档](https://developers.openai.com/api/docs/guides/file-inputs)：支持的 API 与模型可以结合 PDF 文本和页面图像处理文件。此处只是可参考的公开实现路径，不能推断为所有 Codex 桌面功能或其他模型厂商的内部实现。

## 源码检查发现

以下基于提供的 Claurst 0.2.0 源码静态检查，尚未实测；它们是实施约束，不是用户已经确认的产品取舍。路径相对于上游源码目录。

- `src-rust/crates/tools/src/file_read.rs:39` 与 `:127`：Read 不直接提取 PDF 或解码本地图片。`file_write.rs:14` 与 `:107`：Write 接收文本内容。此次检查未发现 DOCX/XLSX 原生解析或生成能力；完整文档工作流需补充实现和运行依赖。
- `src-rust/crates/tools/src/web_search.rs:70` 与 `:247`：搜索服务支持 SearXNG、Brave、Serply；未配置时使用 DuckDuckGo Instant Answer，不等同于完整网页搜索。分支按配置选择，不是失败后的自动回退。
- `src-rust/crates/tools/src/web_fetch.rs:95`、`:327`、`:368`：基础网页抓取无需额外密钥，但部分内容语义提取路径固定使用 Anthropic 模型，需检查并调整为与产品的模型配置相符。
- `src-rust/crates/acp/src/permission.rs:70`：ACP 有工具操作确认及取消机制。`server.rs:104` 与 `:166`：不支持 session/load；桌面应用重启后的会话恢复需额外实现或适配。
