**What to build:** 任务运行期间可以停止、补充要求或回答助手的关键问题，再继续工作。

**Blocked by:** 04: 修改文件并查看真实差异

**Status:** ready-for-agent

- [x] 模型输出、文件工具运行和等待输入期间均可发出停止；停止后不调度新操作，清楚显示尚在结束的操作。
- [x] 补充要求保留顺序，区分已收到和已应用；必要时停止后以新要求继续。

- [x] 继续不自动重放已完成的有副作用操作；旧执行的迟到事件不能污染新执行。
- [x] 在同一任务集成边界验证停止、失败、等待输入与继续；已写入成果保留并说明中止不等于撤销。
