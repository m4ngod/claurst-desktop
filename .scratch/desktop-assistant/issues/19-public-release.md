**What to build:** 提供与源码版本一致的 Apple 芯片 Mac 下载包、构建说明和兼容范围。

- [ ] 对同一发布候选版本确认编程、研究、权限、停止恢复与安装验收证据；任一主流程未通过不宣称首版完成。

- [ ] 提供源码构建、安装、配置、模型能力与已知限制说明；下载文件可校验且与发布源码对应。
- [ ] 在用户指定的 GitHub 仓库发布并验证源码和下载入口；该任务的本地完成部分不等于已经公开发布。

## 验证约定

优先通过桌面所调用的完整任务入口验证用户可观察的行为；复用现有 Claurst 测试边界。只在模型或外部网络边界使用确定性替身，文件、工具与成果尽量真实。涉及真实模型或安装发布的验收必须取得真实证据，不用模拟结果替代。
