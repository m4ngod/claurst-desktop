# 12: 识别扫描 PDF 与图片

**What to build:** 从扫描资料和图片提取可核对的内容，并标明识别不可靠的部分。

**Blocked by:** 02: 配置模型并获得真实回复; 10: 读取 PDF 与 Word 并核对出处

**Status:** ready-for-agent

- [x] 支持扫描 PDF 页面与图片，优先本地识别；需要模型视觉理解时使用已配置且验证有相应能力的非 Claude 服务。
- [x] 按页面或区域返回定位，能够核对印刷文字和表格关键数字；固定测试样本及预期字段。
- [x] 低清、缺页、手写、公式或复杂表格无法可靠识别时提示并保留原图，不补造数据。
- [x] 缺少视觉能力或识别依赖有可操作提示；验证真实解析/识别结果与任务侧栏一致。

## 验证约定

优先通过桌面所调用的完整任务入口验证用户可观察的行为；复用现有 Claurst 测试边界。只在模型或外部网络边界使用确定性替身，文件、工具与成果尽量真实。涉及真实模型或安装发布的验收必须取得真实证据，不用模拟结果替代。
