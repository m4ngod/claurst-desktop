# 个性化与记忆：7 项任务拆分提案

日期：2026-10-26
依据：[正式规格](spec.md)。用户已于 2026-10-26 批准本提案，7 个独立任务现已发布，见 [任务索引](tickets.md)。本文件保留批准时的拆分，不替代各任务执行记录。

每项交付从设置/任务入口贯穿真实运行时、保存和验证。已有测试随各项实现同步扩展，最后一项不是把测试集中留到最后。未发现必须独立安排的广泛重构；必要的局部整理放入对应任务，保持现有行为。

1. **填写自定义指令并让任务遵循**
   - **Blocked by:** None。
   - **交付：** 在设置中编辑、保存、清空应用级做事规则，保存后下一次发送（包括继续已有任务）使用新版本，重启保留。
   - **验收重点：** 真实模型请求包含正确版本；运行中请求不被改写；旧隐藏指令不会累计；原有模型配置保留；保存失败不损坏旧数据；持久偏好不扩大工具权限。建立复用的个性化加载路径，保持 A 布局。
   - **规格覆盖：** 用户故事 1–3、5–7、10、29、32。

2. **编辑 Soul 并导入导出文件**
   - **Blocked by:** 01 填写自定义指令并让任务遵循。
   - **交付：** 独立 Soul 编辑器，导入 SOUL.md 到草稿、保存后生效，并导出当前内容。
   - **验收重点：** 导入可取消、无效文本不覆盖原数据、导出往返一致、重启保留；完整任务中同时使用两类设定；自定义规则与 Soul 冲突时规则优先，当前任务要求优先于持久偏好；导入文件不触发脚本或外部资源加载。
   - **规格覆盖：** 用户故事 4–10、32。

3. **开启个人记忆并在新会话使用**
   - **Blocked by:** 01 填写自定义指令并让任务遵循。
   - **交付：** 默认关闭的记忆开关；开启后从完成的普通任务自动提取个人偏好，在管理列表查看来源、删除单条，并在新会话使用；关闭停止新增与引用但保留数据，重新开启恢复使用。
   - **验收重点：** 使用同一非 Claude 服务；仅处理开启后的新轮次，不回填旧历史；基础去重及容量限制；本阶段仅接受确定的个人偏好，项目/不确定候选不得进入全局记忆；取消、停止、错误不保存半成品。关闭与单条删除立即使后续请求及迟到提取失效；删除后旧轮次不再写回；主任务成果不受整理失败影响。检查真正请求、落盘和重启结果。
   - **规格覆盖：** 用户故事 11–12、15–16、18、21–24、29–31。
   - **边界：** 该任务完成后仅交付个人记忆，不提前声称项目记忆或临时会话完成；源文件与网页内容不能成为全局指令。

4. **按工作区保存和使用项目记忆**
   - **Blocked by:** 03 开启个人记忆并在新会话使用。
   - **交付：** 自动整理项目事实，管理列表可区分个人与当前工作区；同一工作区的新会话可用项目记忆，其他工作区只共享个人偏好。
   - **验收重点：** 工作区身份不依赖显示名；同名工作区、无工作区、重启及路径规范化场景下不串用；分类不明信息只留当前工作区；B 的提取、选择与执行请求均不携带 A 的项目内容；当前范围的开关、单条删除继续有效。
   - **规格覆盖：** 用户故事 13–16、18、21–24、32。

5. **更正记忆并按范围清空**
   - **Blocked by:** 04 按工作区保存和使用项目记忆。
   - **交付：** 编辑记忆、查看时间及来源状态，按个人、当前工作区或全部范围清空，显示影响范围后确认。
   - **验收重点：** 手动编辑不被自动提取静默覆盖；自动候选冲突跳过并提示；保存失败保留旧值；编辑和清空在并发提取、工具循环、重启后仍生效；不依靠保留被删正文阻止重建；历史、个性化设定及项目指令文件不被清空操作连带删除。
   - **规格覆盖：** 用户故事 16–20、23–24、29–30。

6. **创建不保存历史的临时会话**
   - **Blocked by:** 02 编辑 Soul 并导入导出文件；03 开启个人记忆并在新会话使用。
   - **交付：** 新建临时任务，有持续标识；使用自定义指令和 Soul，跳过全部记忆读写，在本次运行可停止/继续；退出后不出现在可恢复历史，真实文件成果保留。
   - **验收重点：** 从创建时确定模式，不靠列表隐藏；桌面与运行时的历史、摘要、日志、自动保存路径均不能留下可恢复聊天正文；正常及强制退出验证；普通任务恢复不受影响；明确远端服务仍收到必要内容、退出后临时变更预览不保留。
   - **规格覆盖：** 用户故事 25–29、32。
   - **依赖解释：** 临时模式在统一记忆入口上整体跳过读取/提取，因此不需要等待项目分类或批量管理；第 07 项再验证与全部记忆功能的组合。

7. **验收完整个性化与记忆流程**
   - **Blocked by:** 05 更正记忆并按范围清空；06 创建不保存历史的临时会话。
   - **交付：** 完成从设置到真实普通/临时任务的集成验收，修复组合问题，记录结果及限制。
   - **验收重点：** 用户已确认的真实任务服务/运行时边界，覆盖项目隔离、关闭/删除并发、重启、异常退出；实际界面检查分区、保存反馈、导入导出、临时标识、滚动与键盘；现有普通历史恢复、任务控制、模型配置、成果查看回归；使用现有可用非 Claude 服务进行小规模真实验证，不用模型口头保证替代磁盘检查。
   - **规格覆盖：** 全部用户故事的组合行为，Testing Decisions 1–9；特别检查个人与项目记忆均被临时会话排除。
   - **边界：** 不自动发布新安装包或替换现有公开发布附件。真实服务缺失时记录未通过的验收与阻塞，不伪造完成。
