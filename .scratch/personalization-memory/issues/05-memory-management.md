# 05: 更正记忆并按范围清空

**What to build:** 编辑记忆、查看时间及来源状态，按个人、当前工作区或全部范围清空，显示影响范围后确认。

**Blocked by:** 04 按工作区保存和使用项目记忆

**Status:** ready-for-agent

## Acceptance criteria

- [x] 用户可编辑记忆，并查看更新时间、范围及来源状态；来源历史被删除时不伪造可打开来源。
- [x] 手动编辑受到保护，自动提取不得静默覆盖；冲突自动候选跳过并给出简明提示，保存失败保留旧值。
- [x] 清空提供个人、当前工作区及全部记忆的明确范围，执行前显示影响范围并确认；未确认不清空。
- [x] 编辑、清空使旧隐藏上下文、缓存及未结束提取失效，后续模型请求不再携带旧值；工具循环、并发提取及重启后保持一致。
- [x] 已删正文不作为备份保留；最少处理游标或非正文标记阻止旧轮次恢复；用户之后主动重新表达的新输入与旧轮次重放区分。
- [x] 清空不删除聊天历史、自定义指令、Soul、项目素材或项目指令文件；历史删除不默认连带清空独立记忆。
- [x] 完整任务服务测试覆盖范围选择、并发更新、失败和重启；实际检查编辑与清空操作及反馈。
