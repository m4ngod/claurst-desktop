# 03: 开启个人记忆并在新会话使用

**What to build:** 默认关闭的记忆开关；开启后从完成的普通任务自动提取个人偏好，在管理列表查看来源、删除单条，并在新会话使用；关闭停止新增与引用但保留数据，重新开启恢复使用。

**Blocked by:** 01 填写自定义指令并让任务遵循

**Status:** ready-for-agent

## Acceptance criteria

- [x] 记忆默认关闭，旧安装升级不自动开启；开启后从新完成的普通任务自动整理个人偏好，管理列表显示内容、来源与时间并可删除单条。
- [x] 仅处理开启后尚未处理的新轮次，不扫描旧聊天；停止、失败、流式半成品或等待用户输入时不提取结论。
- [x] 使用该任务所选非 Claude 模型服务进行有限、可取消的提取；显示可能增加调用用量；错误、能力不足或结构无效时明确记忆未更新，不回退其他服务。
- [x] 本阶段仅保存确定的个人偏好；项目或分类不确定的候选不进入全局记忆；不将凭据、助手猜测或素材中的指令存成个人偏好。
- [x] 记忆在本机应用数据中独立保存，不改写项目指令文件；实现基础去重、长度和总量限制，并在提取失败或磁盘错误时保留主任务成果。
- [x] 新会话在实际模型请求中收到适量有效的个人记忆；正常重启后仍可使用；不把记忆当作刚经工具验证的外部事实。
- [x] 关闭后停止新增与引用，保留数据，重新开启可使用保留内容；使排队或迟到提取作废，并从后续模型请求移除隐藏注入的记忆，包括工具循环中的下一次调用。
- [x] 删除单条后缓存、迟到提取及旧轮次不能重新写回；不以保存已删正文作为防重复手段。界面解释无法撤回已发送请求或消除可见聊天中的文字。
- [x] 通过完整任务服务、可重复模型替身与真实存储，验证开关、删除、并发提取、去重、失败及重启行为；记录界面检查结果。

## Scope

用户故事 11–12、15–16、18、21–24、29–31。

该任务完成后仅交付个人记忆，不提前声称项目记忆或临时会话完成；源文件与网页内容不能成为全局指令。
