# 01: 填写自定义指令并让任务遵循

**What to build:** 在设置中编辑、保存、清空应用级做事规则，保存后下一次发送（包括继续已有任务）使用新版本，重启保留。

**Blocked by:** None

**Status:** ready-for-agent

## Acceptance criteria

- [x] 设置提供应用级自定义指令的编辑、显式保存和清空；保留已有模型配置、连接检查、A 布局及现有功能。
- [x] 经真实桌面任务服务和 Claurst 运行时，新任务及已有任务下一次发送均使用已保存的新版本；旧隐藏指令不累计，运行中请求和可见历史不被篡改。
- [x] 正常重启后设定保留；旧安装迁移不丢失模型与任务历史；保存失败保留原数据并显示错误。
- [x] 当前任务明确要求优先于持久偏好；具体项目约束和应用工具权限不被个性化覆盖；文件或网页中的文字不得改变配置。
- [x] 界面明确本机保存、生效时点以及相关设定会发给所选模型；保存反馈和键盘操作可用。
- [x] 扩展现有完整任务服务测试，检查实际模型请求和真实持久化结果；完成设置界面检查并记录证据。
