# 02: 编辑 Soul 并导入导出文件

**What to build:** 独立 Soul 编辑器，导入 SOUL.md 到草稿、保存后生效，并导出当前内容。

**Blocked by:** 01 填写自定义指令并让任务遵循

**Status:** ready-for-agent

## Acceptance criteria

- [x] Soul 与自定义指令分别编辑、显式保存、清空，并能在重启后恢复；下一次发送同时加载二者的正确版本。
- [x] 导入 SOUL.md 只填入未保存草稿，可预览、修改或取消；保存前不影响实际任务。
- [x] 导出到用户选择的位置，内容与当前导出对象一致；存在未保存修改时明确导出的是当前编辑内容还是已保存内容，不静默混淆。导入导出往返可验证。
- [x] 拒绝无效编码或超限输入并说明原因；取消、读取或保存失败不覆盖已保存数据；记录采用的文本容量边界。
- [x] 自定义做事规则优先于冲突的 Soul 风格，当前任务要求优先于持久设定；导入文件不触发其中提及的脚本或外部资源。
- [x] 通过真实任务服务检查两类设定的上下文和更新行为，并实际验证导入、保存、取消、导出界面。
