# 04: 按工作区保存和使用项目记忆

**What to build:** 自动整理项目事实，管理列表可区分个人与当前工作区；同一工作区的新会话可用项目记忆，其他工作区只共享个人偏好。

**Blocked by:** 03 开启个人记忆并在新会话使用

**Status:** ready-for-agent

## Acceptance criteria

- [x] 自动整理项目事实，记忆列表区分个人与当前工作区，并记录来源、时间和工作区身份；分类不确定的信息只保留在当前工作区，无工作区时不提升为个人记忆。
- [x] 工作区身份依据受授权工作区标识与规范路径，不依据显示名；不自动合并移动后的目录。
- [x] 同工作区的新会话能使用其项目记忆，其他工作区只共享个人偏好；无工作区任务只能使用个人记忆。
- [x] 测试不同目录同名、路径规范化、重启及无工作区场景；项目 A 的内容不得进入 B 的记忆选择、提取或执行模型请求。
- [x] 开关同时覆盖个人和项目记忆，单条删除与迟到提取失效规则同样适用于项目记录；记忆只作上下文，不授予文件访问权限。
- [x] 通过真实任务服务检查跨工作区实际请求及持久化结果，并实际检查范围展示与来源。

## Scope

用户故事 13–16、18、21–24、32。
