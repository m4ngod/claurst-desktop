# 06: 创建不保存历史的临时会话

**What to build:** 新建临时任务，有持续标识；使用自定义指令和 Soul，跳过全部记忆读写，在本次运行可停止/继续；退出后不出现在可恢复历史，真实文件成果保留。

**Blocked by:** 02 编辑 Soul 并导入导出文件；03 开启个人记忆并在新会话使用

**Status:** ready-for-agent

## Acceptance criteria

- [x] 新建任务时可选择临时模式并持续显示标识；普通与临时模式在创建时固定，不把现有普通历史转换成临时。
- [x] 临时会话使用自定义指令和 Soul，并在统一策略入口跳过全部记忆读取、选择、提取和保存，而不只是清空界面列表。
- [x] 本次应用运行内可停止、继续和回答问题；原有文件与工具授权保持。
- [x] 临时会话从一开始不写入桌面历史、运行时会话持久化、恢复快照及包含可恢复聊天正文的摘要或日志；逐一核查实际写盘路径。
- [x] 正常退出及强制结束后，重启不恢复临时任务；真实新建或修改的成果文件保留，退出后不承诺保留临时变更预览或恢复按钮。
- [x] 界面解释临时会话仍发必要内容给所选模型，不能控制提供方数据保留，也不自动撤销文件改动。
- [x] 真实任务服务和子进程终止测试检查应用及运行时数据目录，不能只断言侧栏为空；普通会话持久化与恢复不受影响。
- [x] 实际检查临时入口、持续标识、个性化生效及停止/继续；第 07 项补验个人和项目记忆同时存在时的组合。

## Scope

用户故事 25–29、32。

临时模式在统一记忆入口上整体跳过读取/提取，因此不需要等待项目分类或批量管理；第 07 项再验证与全部记忆功能的组合。
